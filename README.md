# ⚓ Anchor Study

**Stay focused. Stay grounded.**

Anchor Study is a student companion designed to help students stay organised, build consistent study habits and keep their academic goals in sight. Built with a Christian foundation, it brings academic productivity and personal reflection together in one place.

## Features

* **Dashboard:** A central place to access your study activities.
* **Study Planner:** Organise your academic work and study sessions.
* **Focus Timer:** Set aside dedicated time for focused studying.
* **Task Management:** Keep track of assignments and other academic responsibilities.
* **Notes:** Keep your study notes organised.
* **Goals:** Set academic goals and monitor your progress.
* **Scripture Library:** Keep meaningful Bible verses close.
* **Prayer Journal:** Record prayer points and reflections.
* **Devotionals:** Engage with faith-based devotional content.
* **Reflections:** Make space for personal reflection.
* **Profile and Settings:** Manage your account and personalise your experience.

*Features may evolve as development continues.*

## Getting Started

Follow these steps to run Anchor Study locally.

### Prerequisites

* Python 3.13 or a compatible Python version
* Git
* A code editor such as Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/chiyevopchikaonda-stack/anchor-study.git
   ```

2. Enter the project directory:

   ```bash
   cd anchor-study
   ```

3. Create a virtual environment:

   ```bash
   python -m venv venv
   ```

4. Activate the virtual environment on Windows:

   ```powershell
   .\venv\Scripts\Activate.ps1
   ```

5. Install the required dependencies:

   ```bash
   pip install Flask Flask-SQLAlchemy
   ```

6. Start the application:

   ```bash
   python app.py
   ```

7. Open your browser and visit:

   ```text
   http://127.0.0.1:5000
   ```

### Alternative activation for Command Prompt

If you're using Windows Command Prompt instead of PowerShell, activate the virtual environment with:

```bat
venv\Scripts\activate.bat
```
